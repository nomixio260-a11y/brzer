      記号の読み方

      枠の形が敵味方を、中の絵が兵科を表す。 ◇菱形＝敵、□長方形＝友軍、四つ葉＝正体不明。 無線で聞いた内容から、貴官がこれを地図に書き込む。

        操作

        • 地図を叩く ─ 選択中の記号を書き込む（敵の位置は、聞いて、自分で置く）
        • 地図を掴んで動かす ─ 図面をずらす ／ 二本指・車輪 ─ 拡大縮小
        • 記号を掴んで動かす ─ 位置を直す ／ 長押し・右クリック ─ 消す
        • 無線の一行を叩く ─ その方眼へ跳ぶ。「記号」を押せば聞いた位置に一発で置ける
        • 部隊一覧の「記号」 ─ その部隊の駒を、最後に聞いた方眼に置く。 名前は呼出符号がそのまま入り、二度目からは同じ駒が動く。打ち直しは要らない
        • ラベルの見本 ─ 記号を置くと名前の欄が出る。 「戦車2両」「一個分隊」などを一つ叩けば入る（自軍の記号なら見本は呼出符号）
        • 命令 ─ 部隊 → 分類（機動／火力／交戦規定／情報）→ 命令 → 目標（地図を叩く）→ 送信。 目標を叩くと地図の下に「送信」が出るので、命令の頁を開き直さずに送り切れる
        • 前進と攻撃は違う ─ 前進は接敵したら止まって撃つ。 攻撃は止まらず目標まで寄せ続ける。近接すれば掩体の値打ちは落ちるので、 厚い遮蔽の敵は「攻撃」で押し込むしかない ─ ただし寄る間はずっと撃たれる
        • 経路の指定 ─ 移動・前進・攻撃・偵察・後退は、地図を続けて叩けば経由地を積める。 「どこを通れ」まで指定できる。決まったら決定を押す
        • 交戦規定 ─ 死守／陣地防御／弾力防御。部下がどこまで独断で下がってよいかの枠。 細かく指図しなくても、枠さえ決めておけば分隊長は自分で判断する
        • 予令 ─ 命令に発動条件（接敵時／被圧時／統制線／時刻）を付けて先に渡せる。 条件が満ちれば部下は貴官を待たずに動き、動いたことを報告してくる
        • 統制線 ─ 図式で線を引くと名前が付く（統制線甲、乙…）。 「統制線甲を敵が越えたら下がれ」という予令が出せる。 ただし越えたことに気づくのは、そこを見ている部下だけである
        • 射撃要領 ─ 砲撃要請では態勢の欄が着発／曳火／制圧／一斉射に変わる。 掩体の敵には曳火、渡らせたくない時は制圧、奇襲には一斉射。同じ弾数でも効き方が違う
        • 概定射点 ─ 撃つ前に地点を標定させておくと、以後そこへの射撃は早く、正確に落ちる（3点まで）
        • 砲は動かせる ─ ソーンの射程は4200m。前へ出せば届くが、 陣地変換のあいだ（約105秒）は撃てない。射撃中止で、まだ撃っていない弾は止められる
        • 装甲には向きがある ─ 正面から抜けない砲でも、横腹と背中は抜ける。 交戦中の車輌は撃ち合っている相手を向くので、対戦車班をどこに置くかで結果が変わる
        • 操作の早見表 ─ 戦闘中でも地図右上の「?」で開ける （鍵盤なら ?）。この頁には戻れないので、覚える必要はない

                    v4.0「評議会」

                    貴官の背後に立っている四人は、望むものが違う

                    評議会 ─ 反対する者

                    指標と政令だけを置いたとき、この画面には反対する者がいなかった。 机の上で数字を動かせば、そのとおりに国が動く ─ それは統治ではなく、家計簿である。

                    • 四つの塊。軍部（兵と弾。仲間を除かれないこと）／ 民政（法で治めること、恐怖で治めないこと）／ 保安（統制と恐怖。緩めれば、緩めた者を見ている）／ 産業（税は軽く、徴発は控えめに）。席にはそれぞれ名前がある。
                    • どの政令にも必ず怒る者がいる。十三種すべてに、喜ぶ側と怒る側が付いた ─ 誰の顔も立てない晩というものが無い。継続の令は、敷いている限り毎晩怒られる。
                    • 支持は帳簿ではなく仕事量である。軍部が離れれば補充と砲弾は前線に着かず、 民政が離れれば救済は金だけ消えて誰にも届かず、産業が離れれば税収が落ち、 保安が離れれば締めた統制が毎晩こぼれる。
                    • 離反にも期限がある。支持が線を割った省庁は評議会を離れる構えを見せ、 戻せなければ次の朝、国は貴官の手を離れる ─ 参謀本部の接収、行政の停止、密告の網の反転、生産の停止。
                    • 更迭すれば通告は止まる。逆らわない者が座り、二度と逆らわない ─ 二度と働きもしない。残る三つは「次は自分だ」と考えはじめる。

                    上奏 ─ 決めないことも決定である

                    • 一番不満を溜めている省庁が、夜のうちに一件だけ持ってくる。 倉の管理権、令状への署名、非常措置、鉱山の減税 ─ 十二種。
                    • 容れれば彼らは付き、他が離れる。退ければその逆。 どちらの側にも、指標と国庫と支持の代価が札で並ぶ。
                    • 答えないまま出撃すれば、退けたものとして数えられる （面と向かって断るよりは軽い）。同じ省庁が連夜で来ることはない。
                    • 誰が持ってくるかに賽は無い ─ 貴官が前の晩に何をしたかで決まっている。

                    恐怖のもう一つの見返り

                    • 恐怖の高い国では、誰も反対を口に出さない。 政令に対する反発が半分になる ─ 減るのは下がるぶんだけで、上がるぶんは上がらない。 恐怖で買えるのは沈黙であって、支持ではない。
                    • 払うものは変わらない。恐怖はそのまま、前線から上がってくる報告を甘くする。

                    国政 ─ 貴官は議長である

                    戦争は前線だけで行われるものではない。弾を作るのは工場であり、兵を出すのは町であり、 その町を保たせるのは統治である。できないのは、代償を払わずに済ませることだけである。 ─ 扱うのは架空国家の統治であり、実在の国も民族も史実も、ここには無い。

                    • 指標は四つ。民心（兵の質と、内乱までの余裕）／ 統制（動揺は抑えるが、恐怖を生む）／ 忠誠（尽きれば士官団が造反する）／国庫（政令はすべてここから出る）。
                    • 政令は一晩に二つまで。徴兵・徴発・戒厳令・情報統制・保安部の拡張・増産・増税・ 志願兵募集・救済・恩赦・叙勲・報道の解禁 ─ 十三種。 出したものは翌日ではなく今日の戦闘から効く。
                    • 継続の令は解くまで毎晩効き続ける。解けば得たものは返るが、 恐怖だけは半分しか戻らない ─ 一度密告された町は、令が解かれても隣人を信じない。
                    • 善政も悪政も選べる。どちらにも帰結がある ─ 忠誠が尽きれば造反、民心が尽きれば内乱。どちらでも、その場で失脚する。
                    • 講評は説教をしない。何をしたかを数え、何が起きたかを並べるだけである （苛政／寛政／硬軟／中庸）。

                    恐怖は、貴官の目を潰す

                    この更新の肝はここにある。 恐怖で統治された軍では、部下は悪い報せを上げない。

                    • 戒厳令・情報統制・保安部・粛清は恐怖を生む。恐怖が高いほど、 前線から上がってくる報告が甘くなる。
                    • 三分の一まで削られた分隊が「六割は残っている」と報告する。 弾が尽きかけていても「まだある」と言う。負傷者の数は、いちばん言いにくい数字である。
                    • 敵も小さく報告される ─ 「大部隊が来ている」と言えば、 なぜ止められないのかを問われるからである。
                    • 嘘をつくのではない。「まだ保っている」と言い続けるだけである。 そして本当に保たなくなった日、その部隊は前触れもなく消える。
                    • 歪むのは報告だけで、真実は歪まない。情報統制を敷いても、 敵砲兵の落ちる場所も敵の判断も一切変わらない。
                    • 講評には聞いていたこと／起きていたことが二列で並ぶ。 矢印も「だから」も置かない ─ 因果は貴官が結ぶ。
                    • 報道の解禁で恐怖は下がる。損害が国民に知れる代わりに、 前線からの報告は正直になる。

                    士官団 ─ 粛清と叙勲

                    • 将校一人ひとりに忠誠が付いた。心服／従順／面従／不満／離反寸前。 付いていない者は命令の呑み込みが遅く、渋る。
                    • 粛清できる。統制は上がり、忠誠と民心は下がる。 取り返しはつかない ─ 経歴も特性も戻らず、代わりに来るのは 忠誠だけは高い、腕の無い者である。
                    • ただし代価は相手による。離れかけている者を除くなら士官団は揺れない。 よく戦っている者を除けば、その日から誰も貴官を信じない。 代価は押す前に画面に出る。
                    • 叙勲で忠誠は買える。買えるうちは安い。
                    • 取り返しのつかない決定には、一手が挟まる。

                    戦役 ─ 継戦（v2.0）

                    • 三日を続けて戦う。峠で時間を稼ぎ、橋で敵を止め、奪われた町を取り返す。 部隊は一つしかない ─ 損害・弾薬・疲労・士気・経歴は、そのまま翌日へ持ち越される。
                    • 戦線が動く。勝てば前へ出て、負ければ下がる。0まで押し込まれれば、そこで戦役は終わる。
                    • 補充と弾薬を配る。一晩に一個の分隊へ入れられる補充は4名まで。 分隊は一晩では生えてこない。
                    • 今夜の使い方を一つ選ぶ ─ 休養（疲労が抜ける）／ 陣地構築（防御につく部隊が構築陣地から始まる）／ 夜間偵察（夜明けに敵の集結が分かる）。三つとも欲しいのが常である。
                    • 戦役の進み具合はブラウザに残る。閉じても続きから戦える。

                    将校と経歴

                    • 部下に名前と気質が付いた。沈着・果敢・慎重・几帳面・一徹の五つ。 気質は命令の呑み込み・独断・腰の据わり・口数・射撃の統制・部下の扱いに効く。 同じ「歩兵分隊」でも、率いる者が違えば別の部隊になる。
                    • 特性は与えるものではなく、生えるもの。砲撃を浴びて線を動かさなければ「不動」、 潰れる前に下がれば「深慮」、要らないことを言わなければ「寡黙」。 戦闘のあとで、その日の振る舞いから付く。
                    • 生き延びた戦闘が経験になる。新編 → 実戦経験あり → 古参 → 歴戦 → 精鋭。 腕と腰に出る。
                    • 部隊が消えれば、率いていた者も帰ってこない。空席には代わりが来るが、経歴は引き継がれない。

                    任務編成 ─ 分派

                    • 戦闘前に、分隊へ分派を付けられる（1個の部隊に2つまで）。 機関銃班（制圧力＋／足が鈍る）、対戦車小隊（歩兵が戦車の前に立てる）、 工兵班（穴が深くなり、鉄条網と地雷原を処理できる）、 観測班（見える範囲と報告の精度）、衛生班（倒れた者が戻る）、 無線中継班（谷底でも繋がる）。
                    • 編成表の「歩兵分隊」は紙の上の話である。線に出るのは、その分隊に何を付けたかで決まる。

                    作戦命令 ─ H時前

                    • 戦闘は「H時前」から始まる。時計は止まっており、部下はまだ目の前にいる。
                    • ここで渡す命令は無線に乗らない。遅れず、歪まず、網も埋めない。復唱もその場で返る。
                    • 概定射点も、H時前に立てたものは前夜のうちに諸元が出ている（標定の3分が要らない）。 火力計画とはそういうものである。
                    • ただしH時前に分かっているのは自分の企図だけで、敵の企図ではない。 渡せるのは「そのつもりでいろ」までである。
                    • 「H時」を宣言した瞬間から、貴官と部下を繋ぐのは無線だけになる。

                    直したもの

                    • 報告の文面が、盤を回す乱数を消費していた。言い回しが一語変われば 以後の弾着点も敵の判断もずれる ─ つまり情報統制を敷くと敵砲兵の落ちる場所が 変わっていた。文面用の乱数列を分け、恐怖 0 と 0.9 で盤が完全に一致することを 検査で毎回確かめるようにした。
                    • 同じ電文が、本文で「3/9名」と言いながら部隊一覧を「7/9名」に書き替えていた。 部下が自分について言うことを一箇所に集約した。
                    • 戦闘中に読み込み直して出撃し直すと、その晩の決算が何度でも走っていた。 押すだけで国庫も補充も無限に湧く穴だった。一晩は一度しか明けない。
                    • 継続の令を敷いて解くだけで民心が増えていた。目盛りが底で詰まっているとき、 取られた以上が返っていた ─ 内乱がまるごと無効化できた。 返すのは表の値ではなく、実際に動いた分だけにした。
